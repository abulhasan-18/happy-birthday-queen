## ✨ Features & Magic

### ⏳ 1. India Standard Time (IST) 3D Flip Countdown
- 🇮🇳 **Target Time:** November 2nd, 00:00:00 IST (India Standard Time).
- 🔄 **3D Card Flip Animation:** Numbers flip smoothly every second (`34, 33, 32...`).
- 💎 **Smart Zero-Day Suppression:** If there are 0 days remaining, it automatically hides the days card and displays only `Hours : Minutes : Seconds`.
- 🌸 **Mysterious & Minimal:** Kept clean, silent, and clutter-free until the big moment arrives!

---

### 🏹 2. Scene 1 – The Slingshot
- 🎯 **Automatic & Manual Firing:** The wooden slingshot smoothly draws back elastic tension, aims, and launches automatically at the glowing floating heart (or tap to shoot!).
- 💥 **Direct Hit Explosion:** Striking the heart triggers a 360° explosion of 36+ fluttering mini hearts and transitions to the reveal!
- 🏹 **Only Way Through:** No skip buttons — hitting the heart is the true key to unlocking the gift.

---

### 💌 3. Scene 2 – The Reveal
- 🌹 **Smooth Slide Transition:** Transitions into a solid coral-red canvas.
- ✍️ **Typewriter Letter-by-Letter Animation:** Animates in character-by-character:
  - `Happy Birthday`
  - `Queen uhhh` 👑
- 👑 **Royal Crown Landing:** A crown gently lands atop her name with fairy sparkle effects.

---

### 🌳 4. Scene 3 – The Heart Tree
- 🌿 **Organic Branch Growth:** A bare brown tree trunk grows upward and splits into graceful curved limbs.
- 💖 **100+ Blooming Hearts & Her Emojis:** Vibrant ruby, rose, and golden hearts sequentially bloom into a full heart-shaped canopy, sprinkled with Her Majesty's signature **🙄** and **🥴** faces!
- 🌱 **Tap to Grow More:** Every tap anywhere on the canopy permanently blossoms 3 new hearts and emojis that stay on the tree, making it denser and fuller with every touch!
- 🎉 **Automatic Celebrations:** Confetti showers burst continuously every 3 seconds.
- 💌 **Royal Dedication Card:** Stamped with *With Love, Smokiee • Always & Forever Love ❤️ 🙄🥴*.

---

### 🎶 5. Continuous Romantic Melody
- 🎵 Powered by a custom **Web Audio API** synthesizer.
- 🎼 Plays a gentle music box lullaby continuously and loops forever without stopping.
- ⚡ 100% self-contained — zero external mp3 files or broken asset links!

## 🚀 Routes

| Route | Description |
| :--- | :--- |
| **`/`** | **Main Countdown Page:** Targets Nov 2nd 00:00:00 IST. Automatically unlocks into the full gift when Her Majesty's birthday arrives! |
| **`/?preview=true`** | **Instant Gift Preview:** Bypasses the countdown for immediate viewing. |
| **`/demo`** | **10-Second Flip Demo:** Counts down `10, 9, 8...` with 3D flip cards, bursts confetti, and unlocks the gift. |

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, React 19)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Typography:** Google Fonts (`Outfit`, `Dancing Script`, `Cinzel`)
- **Sound:** Web Audio API (Synthesized music box & chimes)
- **Effects:** Canvas Confetti, CSS 3D Transforms, Responsive SVGs

## 💻 Running Locally

```bash
# 1. Clone repository
git clone https://github.com/abulhasan-18/happy-birthday-queen.git
cd happy-birthday-queen

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Open in browser
# http://localhost:3000
```
